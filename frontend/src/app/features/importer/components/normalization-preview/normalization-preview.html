Qué cambia al normalizar

Las reglas usan el destino Darwin Core mapeado, no la apariencia del valor. No convierten identificadores ni texto libre a números. No convierten DMS ni inventan datum, unidades o componentes de fecha. Los formatos no reconocidos se conservan.

NULL y N/A siguen siendo datos salvo aprobación explícita. Aplicar actualiza únicamente el diagnóstico. JSON y CSV son informes de incidencias, no descargas de registros.
