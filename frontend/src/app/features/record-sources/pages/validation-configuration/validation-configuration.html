Alcance de la configuración

Se guardan los campos elegidos de las cinco fuentes. Si alguien guardó otros cambios antes, se rechaza el guardado para no borrar cambios de otra persona. Cargar configuración guardada reemplaza sus cambios solo cuando se haya podido obtener la configuración guardada. Si falla, sus cambios se conservan.

Solo los campos obligatorios generan incidencias por datos ausentes; los opcionales permanecen configurados. La obligatoriedad configurada orienta el diagnóstico, no certifica una publicación SiB ni modifica el vocabulario TDWG. Las comprobaciones básicas de fechas y coordenadas siguen activas.

Al salir con cambios o una entrada sin agregar, se solicita confirmación. Mientras se guarda o se carga la configuración, no se puede editar; un fallo conserva sus cambios.
