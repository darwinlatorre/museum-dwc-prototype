Dirección 01 · Hoja ancha

Ilustración interactiva, no motor de normalización ni validación TDWG completa. Recomendación: más espacio para comparar registros, menos paneles permanentes.

Interpretación y límites de las reglas

Todos los controles empiezan apagados. Cada cambio vuelve al original. Fechas: solo el ejemplo inequívoco 2024/02/29 pasa a 2024-02-29. 03/04/2024 queda intacto. Se conservan año, mes, fecha-hora e intervalos ISO; no se inventa zona horaria. Coordenadas: solo ilustramos coma decimal explícita; no cambia datum, unidades ni DMS. Números: solo individualCount y sampleSizeValue mapeados; nunca identificadores ni measurementValue.

Active coma decimal solo si conoce el origen. Se conserva cada dígito; no se usa redondeo. NULL/N/A se tratan como datos salvo consentimiento del control correspondiente.

Grupos de coincidencias · avisos, no eliminación

Una repetición de occurrenceID no demuestra un error biológico. Sin esa columna, se comparan igualmente todas las filas completas. Ocultar columnas no altera las coincidencias.

Leyenda: borde y texto de regla = cambio. Espacios visibles como ␠, tabulaciones como ⇥, salto como ↵; ∅ = vacío. Pase el puntero, enfoque o toque una celda para leer el original. Escape cierra el detalle.
