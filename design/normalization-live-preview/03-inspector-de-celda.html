Interpretación segura y límites DwC

Todos los controles están apagados al inicio. Se recalcula siempre desde el original. Ejemplos ilustrativos, no motor ni validación TDWG completa: 2024/02/29 → 2024-02-29, 2,4500 → 2.4500 y 1,2300 → 1.2300 (solo con modo coma conocido). 03/04/2024 queda intacto. No se completan ISO parciales, fecha-hora o intervalos; no se inventa UTC. No se convierten datum, unidades ni DMS. Cada dígito se conserva, sin Number; IDs y measurementValue (UV-light) no se infieren como números. NULL/N/A solo cambian con consentimiento.

Grupos de coincidencias y filas físicas

Se comparan filas completas incluidas columnas ocultas y, por separado, occurrenceID exacto no blanco aunque difieran otras celdas. No se borran ni fusionan registros. Repetir un ID no prueba un error biológico. Sin columna occurrenceID se mantiene la comparación de filas completas.

Borde y texto de regla = cambiado. ␠ espacio, ⇥ tabulación, ↵ salto, ∅ vacío. Hover, foco o toque seleccionan la celda; Escape limpia el inspector.
